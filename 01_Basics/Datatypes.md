# Object Types / Datatypes

- Numbers : 1234, 3.145, 3+4j, 0b111, Decimal(), Fraction()

- Strings : 'Spam', "Spam's", b'a\x00b'

- Lists : [1,2,3,4] ; ['a', 'b', 'c'] ; [1, [2,"three"],4] ; List(range(10))

- Tuples : (1,2,3,4) ; ('a', 'b', 'c'); namedtuple

- Dictionaries : {'a':1, 'b':2}; dict(hours=10) // indexing doesn't start form 0

- sets : set('abc), {'a','b','c'}, {1,2,3,4,5,6}

- File : open('file.txt', 'r') ; open('file.txt', 'w'); open('file.txt', 'a')

- boolean : True, False

- None : None

-Functions, modueles, classes

- Special types (Advanced) : Decorators, Generators, Iterators, Meta Programming
